 프로젝트 배경

본 프로젝트는 UI/UX 디자인 및 개발 교육 과정의 웹 사이트 리디자인 과제로 진행되었습니다.

프로젝트를 기획할 당시 ONF는 기존 소속사와의 전속계약 종료가 발표된 이후 향후 활동 방향이 공개되지 않은 시점이었습니다. 

 "ONF의 공식 엔터테인먼트 홈페이지는 어떤 사용자 경험을 제공해야 할까?"

라는 가상의 시나리오를 바탕으로 프로젝트를 기획했습니다.

프로젝트를 진행하는 과정에서 실제로 KI ENTERTAINMENT가 설립되고 ONF가 전원 함께 전속계약을 체결하게 되었습니다.


이에 기존 기획 의도를 유지하면서도 실제 운영 환경과 최신 트렌드를 반영하여 KI ENTERTAINMENT 공식 홈페이지 리디자인 프로젝트로 발전시켰습니다.

---

프로젝트 목표

엔터테인먼트 홈페이지의 정보 구조와 사용자 경험을 개선하는 것을 목표로

- 브랜드 아이덴티티 강화
- 정보 구조 개선
- 반응형 웹 구현
- 접근성 향상

을 목표로 리디자인했습니다.

대표 아티스트인 ONF를 중심으로 콘텐츠를 재구성하여 사용자가 원하는 정보를 더욱 직관적으로 탐색할 수 있도록 설계했습니다.

---

Modern Dark Theme

- Desktop (≥1120px)
- Tablet (640~1119px)

 Design Decision

 대표 IP 중심 콘텐츠 구성

프로젝트를 업데이트하는 과정에서 KI ENTERTAINMENT는 ONF를 중심으로 운영되는 엔터테인먼트사였습니다.

이에 대표 아티스트의 활동과 멤버 정보를 우선적으로 배치하여 핵심 콘텐츠의 가시성을 높이고 사용자가 원하는 정보에 빠르게 접근할 수 있도록 정보 구조를 재설계했습니다.
---

다크 테마 적용

엔터테인먼트 산업의 분위기에 맞춰 프리미엄한 이미지를 전달하기 위해 다크 테마를 선택했습니다.

그린 포인트 컬러를 활용하여 브랜드의 신선한 이미지를 강조했습니다.

---

 반응형 UX

모바일 환경에서도 동일한 경험을 제공할 수 있도록

Desktop → Tablet → Mobile

순으로 레이아웃을 최적화했습니다.

---

  접근성 고려

시맨틱 HTML과 ARIA Label을 적용하여 키보드 사용자와 스크린리더 사용자도 이용할 수 있도록 구현했습니다.

---
What I Learned

이번 프로젝트를 통해 엔터테인먼트 홈페이지는 단순히 정보를 제공하는 공간이 아니라, 아티스트 IP와 팬을 연결하는 중요한 접점이라는 점을 배웠습니다. 또한 프로젝트 진행 중 실제 산업 환경이 변화함에 따라 기존 기획을 유지하면서도 현실에 맞게 프로젝트를 업데이트하는 경험을 할 수 있었으며, 변화하는 환경 속에서도 초기 기획 의도를 유지하면서 실제 서비스 환경에 맞게 프로젝트를 개선하는 디자인 프로세스의 중요성을 배웠습니다.
